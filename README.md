# Notebook Page for Codex

Notebook Page formats notes, math, and simple sketches on a ruled sheet you can copy by hand. Worked examples show one step per line, and practice problems leave space for your work.

## Install

1. [Download `notebook-page.zip`](https://github.com/stefanoseni/codex-notebook-page/releases/latest/download/notebook-page.zip) and unzip it.
2. Move the extracted `notebook-page` folder into `~/.codex/skills/`. If you use a custom `CODEX_HOME`, use its `skills` folder instead. Keep `SKILL.md`, `agents/`, and `assets/` together.
3. Open a new Codex chat and try one of the prompts below.

## Try it

- `$notebook-page Give me Pythagorean theorem notes with a labeled triangle.`
- `$notebook-page Give me a fractions problem and leave room for me to solve it.`
- `Put my history notes on a notebook page so I can copy them by hand.`

In Codex surfaces that support inline visualizations, the sheet appears in the reply. On other surfaces, Codex can provide an HTML file you can open in a browser.
